# Brandit website concept

A static concept for a new Brandit Promotional Products site: a campaign-style home page and an enquiry-only shop.

- `index.html` – home page
- `shop.html` – products, product detail, enquiry list and enquiry form
- `dc-lite.js` – small template runtime the two pages share (no dependencies, no build step)
- `assets/` – logo and product images

Open `index.html` in a browser, or serve the folder with any static host.

## Not production yet

- Products, minimum quantities and branding methods are sample data.
- Phone, email, reply time and lead times are bracketed placeholders.
- "Send enquiry" validates the form and shows a confirmation, but nothing is sent anywhere.
- Pages carry `noindex` so the concept is not picked up by search engines.
